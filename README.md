# CommuniAble AI

**AI-powered Workplace Communication Training Platform for Persons with Disabilities**

## Overview
CommuniAble AI is an innovative platform designed to empower Persons with Disabilities (Hearing, Speech, Cognitive, Learning, Visual) with the workplace communication skills they need to thrive. Using advanced AI (speech analysis, contextual learning, and simulated workplace scenarios), the platform provides adaptive, accessible, and personalized training without the traditional constraints of standard e-learning tools.

## Technology Stack
- **Frontend**: Next.js, React, Tailwind CSS
- **Backend API**: FastAPI (Python)
- **Database & Auth**: Supabase (PostgreSQL)
- **AI/LLM Local Processing**: Ollama (for on-device privacy and low-latency inference)
