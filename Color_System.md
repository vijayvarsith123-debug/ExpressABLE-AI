# Color System

## 1. Overview
The color system ensures WCAG 2.2 AA (and in many cases AAA) compliance for contrast ratios. It supports Light, Dark, and High-Contrast themes.

## 2. Brand Colors (Light Theme)
- **Primary:** `#2563EB` (Blue) - Used for primary actions, active states. (Contrast ratio > 4.5:1 on white).
- **Secondary:** `#10B981` (Green) - Used for success states, progression.
- **Accent:** `#F59E0B` (Amber) - Used for highlights, warnings.

## 3. Neutral Palette (Light Theme)
- **Background:** `#F8FAFC` (Slate 50)
- **Surface:** `#FFFFFF`
- **Border:** `#E2E8F0` (Slate 200)
- **Text Primary:** `#0F172A` (Slate 900)
- **Text Secondary:** `#475569` (Slate 600)

## 4. Dark Theme Mapping
- **Primary:** `#3B82F6` (Lighter Blue for better contrast on dark bg)
- **Background:** `#0F172A` (Slate 900)
- **Surface:** `#1E293B` (Slate 800)
- **Text Primary:** `#F8FAFC`
- **Text Secondary:** `#94A3B8`

## 5. High-Contrast Mode
- **Background:** `#000000`
- **Surface:** `#000000` with `#FFFFFF` solid borders.
- **Text:** `#FFFFFF` or `#FFFF00` (Yellow) for focus states.
- **Focus Rings:** `#FFFF00`, 4px solid.
