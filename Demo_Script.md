# Demo Script

## Sequence Outline

### 1. Landing Page -> Accessibility Profile Selection
**Script:** "Welcome to CommuniAble AI. A user begins on our clean landing page. Upon registering, the very first step is the Accessibility Profile. Here, we select 'High Contrast' and 'Screen Reader Support'. Watch the UI instantly adapt."

### 2. Login -> Dashboard
**Script:** "Logging in as a Learner, we arrive at the Dashboard. Notice the uncluttered layout, clear typography, and daily communication goals designed for cognitive ease."

### 3. Workplace Vocabulary
**Script:** "We navigate to Workplace Vocabulary. The user practices essential corporate terminology. Each term includes audio pronunciation, clear definitions, and contextual usage in an office setting."

### 4. Speech Assessment -> AI Feedback
**Script:** "Next, a Speech Assessment. The scenario: 'Asking for a project update'. The user records their voice. Instantly, our AI provides feedback on clarity and tone, formatted in accessible, easy-to-read cards."

### 5. Writing Assessment -> Grammar Suggestions
**Script:** "Moving to written communication. The user drafts an email to a supervisor. The AI suggests improvements for professional tone and clarity, ensuring the message is assertive yet respectful."

### 6. Mock Interview -> Workplace Simulation
**Script:** "The core feature: A Mock Interview. The user engages with our AI avatar. For users who are non-verbal or prefer writing, the typing interface is seamlessly integrated. The simulation evaluates responses against professional standards."

### 7. Progress Dashboard
**Script:** "Back to the Learner Progress Dashboard. Clear visual charts show improvement over time in specific domains like 'Interview Readiness' and 'Verbal Clarity'."

### 8. Trainer Dashboard -> Institution Dashboard
**Script:** "Switching roles. As a Trainer, we see a cohort overview, allowing targeted support for individuals needing manual review. Finally, the Institution Dashboard shows high-level analytics, proving the platform's value in fostering an inclusive workforce."
