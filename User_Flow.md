# User Flows

## 1. Learner Flow: Onboarding & Dashboard
1. **Landing Page:** User clicks 'Get Started'.
2. **Registration:** Enters details, creates account.
3. **Accessibility Profile:** Selects primary needs (e.g., High Contrast, Screen Reader Optimization, Cognitive Ease).
4. **Dashboard:** Lands on personalized dashboard showing daily communication goals, recommended vocabulary, and pending simulations.

## 2. Learner Flow: Speech Assessment
1. **Dashboard:** Clicks 'Start Speech Assessment'.
2. **Pre-check:** Microphone calibration and environmental noise check.
3. **Prompt:** System presents a workplace scenario (e.g., "Ask a colleague for a project update").
4. **Recording:** User records response.
5. **AI Analysis:** System analyzes articulation, tone, and pacing.
6. **Feedback:** Instant feedback provided with visual cues and actionable tips for improvement.

## 3. Learner Flow: Mock Interview
1. **Simulations Menu:** Selects 'Mock Interview'.
2. **Configuration:** Chooses industry and interview type (e.g., HR screening).
3. **Interaction:** Engages in back-and-forth dialogue with AI avatar.
4. **Completion:** Receives comprehensive breakdown of communication effectiveness, body language (if video enabled), and response quality.

## 4. Trainer Flow: Reviewing Learner Progress
1. **Dashboard:** Views alert for "New AI Assessments needing Trainer Review".
2. **Learner List:** Selects specific learner.
3. **Assessment View:** Reviews the audio/text and the AI-generated feedback.
4. **Trainer Input:** Adds manual notes, adjusts AI score if necessary, and sends finalized feedback to the learner.

## 5. Institution Flow: Analytics
1. **Dashboard:** Views aggregated data on platform usage and overall skill improvement metrics.
2. **Reports:** Generates monthly compliance and engagement report.
3. **Export:** Downloads as accessible PDF or CSV.
